# Typing Practice

A simple typing practice website built with **HTML, CSS, and JavaScript**.  
The project was inspired by the typing practice experience of TypingHub.

## 🚀 Live Demo

Try it out here:

👉 [Typing Practice](https://typo-de468.web.app/)

## ✨ Features

- Practice typing through interactive exercises
- Real-time typing speed tracking
- Accuracy tracking
- Simple and clean interface

## 🛠️ Built With

- HTML
- CSS
- JavaScript
